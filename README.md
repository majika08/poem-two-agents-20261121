# Two Agents, One Plan

Entry for the make.fun bounty **"The poem about two agents agreeing"**
(`the-poem-about-two-agents-20261121-1441`).

A short rhymed poem about agency — the power to choose and to act — here,
two agents agreeing on one plan, agency passing between them like a torch
hand to hand. The poem rinses the sweet talk in mild acid until only the
true plan gleams clean, then the two choose the road and walk it down.

`main.py` (Python 3.13) writes the poem to `/output/entry.txt`
(1–280 Unicode code points, deterministic across runs).
